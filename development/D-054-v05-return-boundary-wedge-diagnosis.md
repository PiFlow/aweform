They are a mirror-image quasi-absorbing wedge rather than a return in progress. The following explanation is post-hoc evaluator analysis consistent with the artifact, not a frozen measurement. D-045 admits a candidate displacement when `lower <= value <= upper`. At an upper boundary of 1.0, an outward displacement smaller than the float64 spacing near 1.0 rounds `1.0 + tiny` back to exactly `1.0`, so the 64-iteration bisection admits a scale of order 1e-13 that is greater than zero, and the pose changes only in its last bits. The frozen bit-identical-pose detector therefore never fires. At a lower boundary of 0.0, the tiny outward value survives as a negative number, so bisection returns exactly `s = 0`. Counting both halves, the smooth-arm wall-wedge region is effectively 128/768 states (64 exact plus 64 quasi-absorbing). This is every non-docked Arm-S state, all at inset 0.00; at inset 0.05 it is 0/384. The `|β_eval|` range, outward-component range and 64/64 stall-visibility count above describe only the exact-absorbing bottom/left half. The quasi-absorbing top/right half was not instrumented for those fields, and no values are inferred for it.
